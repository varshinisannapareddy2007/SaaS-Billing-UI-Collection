# SaaS Billing UI Collection

A modern, responsive collection of SaaS billing interfaces designed with a futuristic neon visual style.

## Project Overview

The SaaS Billing UI Collection contains four connected UI templates that represent common billing and subscription workflows:

1. SaaS Pricing
2. Billing Dashboard
3. Payment Checkout
4. Invoices & Billing History

The project demonstrates frontend development using HTML, CSS and JavaScript along with a GitHub collaboration workflow.

## Features

* Modern neon-themed user interface
* Responsive layouts for different screen sizes
* Interactive buttons and components
* Pricing plan selection
* Monthly and yearly billing toggle
* Revenue and subscription dashboard
* Payment method selection
* Card, UPI and net banking forms
* Invoice search and status filtering
* Billing profile section
* Toast notifications
* Connected navigation between all UI templates

## UI Templates

### 01 — SaaS Pricing

A pricing interface for displaying SaaS subscription plans.

Features:

* Orbit, Nova and Galaxy plans
* Monthly/yearly billing toggle
* Feature comparison
* Plan selection
* FAQ section

### 02 — Billing Dashboard

A financial overview dashboard for monitoring SaaS billing activity.

Features:

* Revenue overview
* Active subscriptions
* Pending payments
* Success rate
* Revenue analytics
* Subscription breakdown
* Recent transactions

### 03 — Payment Checkout

A secure-looking checkout interface for processing a SaaS subscription payment.

Features:

* Card payment
* UPI payment
* Net banking
* Card number formatting
* Expiry date formatting
* CVV validation
* Payment confirmation modal
* Order summary

### 04 — Invoices & Billing History

An invoice management interface for viewing billing records.

Features:

* Invoice summary
* Total billed amount
* Paid and outstanding invoices
* Invoice search
* Status filtering
* Invoice download actions
* Billing profile
* Recent payment activity

## How to Run

1. Clone or download the repository.
2. Open the `SaaS-Billing-UI-Collection` folder.
3. Open `index.html` in a web browser.
4. Select any UI template from the main dashboard.
5. Use the dashboard link on each page to return to the main interface.

No backend or database is required.
